This folder contains the dataset collected in the research project
"Rethinking Opinion Measurement Interfaces for Human-in-the-Loop Optimization"
and the notebooks that analyze it.

## Layout

```
analysis
├── *.ipynb          Python and R notebooks, numbered in the order of the paper
├── dataloader.py    loads the raw data into data frames
├── stats.py, stats.R, bayesMannWhitney.R
├── processed/       pre-computed data frames, written and read by the notebooks
├── figures/         figures generated by the notebooks
├── text/            raw data of the text summarization study (download)
└── image/           raw data of the image color enhancement study (download)
```

The notebooks use paths relative to this folder. Python dependencies are
listed in [requirements.txt](./requirements.txt); the figures are rendered
with LaTeX (`text.usetex`). The `*_stats` and `*_lmm` notebooks use an R
kernel with `lme4`, `lmerTest`, `BayesFactor`, `report`, and `ARTool`.

## Raw data

The raw data is not part of the git repository. Download the archives from
the [releases](https://github.com/changkun/rankui/releases) page and extract
them here, so that the `text` and `image` folders sit next to the notebooks:

```
text/{1,2,3,4}/{interface}/     four recruitment batches
image/1/{interface}/            one recruitment batch
```

Each `{interface}` folder (`pointwise`, `pairwise`, `listwise-rating`,
`listwise-notie`, `listwise-cantie`, `listwise-ranking`) contains:

```
tasks/                          the three articles or photos to optimize
prolific_export_{study}.csv     one row per participant
P{nnn}-S{nnn}/                  one session of one participant
├── {task}-begin.json           demographics, asked once before the first task
├── {task}-iter.json            order of the iterations of a task
├── {task}-finish.json          questionnaire answers after a task
├── feedbacks/{iteration}.json  feedback of an iteration: ratings, rankings,
│                               "I don't know", comments, and timestamps
├── parameters/{iteration}/     optimizer parameters of each presented option
└── options/{iteration}/        the presented options (.txt summaries or .jpg photos)
```

## Processed data

The `processed` folder contains the data frames that the notebooks compute
from the raw data. The statistics notebooks read them, so most results can be
reproduced without downloading the raw data.

## Anonymization

Participants were recruited via Prolific and consented to the publication of
their anonymized data. Before the release:

- Prolific participant IDs and submission IDs were replaced with random
  pseudonyms (`P001`-`P360`, `S001`-`S360`) in all folder names, files, and
  notebook outputs. The mapping is not published.
- Only the 360 participants that the paper reports on are included. The data
  of all other submissions was removed, so the total number of collected
  submissions stated in the paper cannot be recomputed from this release.
- The Prolific exports keep the columns the paper reports on (age, sex,
  country of residence, time taken). The values of all other columns
  (ethnicity, nationality, country of birth, language, student and employment
  status, approval statistics, timestamps) are replaced with `REDACTED`, and
  the same holds for `processed/demographics.csv`. The outputs of the cells in
  `1.demographics.ipynb` that inspect these columns are cleared.

## Notes

The notebooks are published as they were used, including their outputs.

- `6.outcomes1` (text) and `6.outcomes2` (image) come from the earlier
  per-domain analyses. Both cache their computed metrics in `processed`
  (`quality.csv`, `quality_image.csv`) and write `quality_progress_{domain}.csv`
  for `6.outcomes_stats1` and `6.outcomes_stats2`. `6.outcomes2` refers to an
  older folder layout (`domain/image/`) when it recomputes from the raw data.
- The sentiment labels in `8.questionnaire_vis` were produced with the OpenAI
  API and are cached in `processed/feedback_sentiment.csv`.
